# Bell Custom Apparel portfolio homepage
The original homepage design and imagery are preserved. Navigation points to real sections, placeholder hero text is replaced, carousel arrows and dots work, and controls can be operated by keyboard.
This is a portfolio sample, not a live ordering site. Order/quote calls to action now point to the services section, and the footer states that ordering and quote requests are not enabled.
Publish the code folder using netlify.toml. The original form files remain in the repository for future work.
